# ⛏️｜NeoMods - Minecraft Mod

**説明：** 艦長が自分用にまとめた Minecraft の Mod。<br>Mod の管理画面と、遊びやすくする小さな機能をひとつにまとめた。

*One jar. Vanilla look. Only what you need.*

## ❱ 情報【Information】

Mod の一覧と設定の画面に、ズーム・ワールドマップ・3D スキンなどの機能を1つの Mod にまとめたもの。<br>
見た目はバニラのまま。機能はすべて設定画面で個別に ON / OFF できる。

```text
Mod      : NeoMods
Version  : 26.3
Loader   : Fabric（Fabric API は不要）
Requires : Minecraft 26.3 / Java 25
Author   : argonaute_nemo
```

---

## ❱ 特徴【Highlights】

- 📦 **1つの jar で完結**：Fabric API などの前提 Mod は要らない
- 🎨 **バニラの見た目**：画面・アイコンはバニラの絵をそのまま使う
- 🔘 **全部 ON / OFF できる**：使わない機能は止めておけば負荷にならない
- 🛟 **古い環境でも止まらない**：版が合わない時は、ゲームを止めずに機能だけを無効にする

---

## ❱ 導入【Introduction】

1. Fabric Loader を入れた Minecraft 26.3 を用意する
2. `NeoMod.jar` を `.minecraft/mods/` に置く
3. 起動して、タイトル画面の「Mods」から設定を開く

---

## ❱ 機能【Features】

| 機能 | 既定 | 内容 |
|---|---|---|
| 📋 Mod の管理画面 | ― | 入っている Mod の一覧・説明・各 Mod の設定画面 |
| 🗺️ ワールドマップ | ON | `M` キーで、両手に持った地図を大きく開く。ピン・テレポート・全画面 |
| 🔭 ズーム | ON | 素手で右クリックを長押し。ホイールで倍率を変える |
| 🎒 インベントリ移動 | ON | インベントリやチェストを開いたまま歩ける |
| 🔁 画面の切り替え | ON | 進捗画面とインベントリを、閉じずに行き来できる |
| 📜 進捗画面の拡大 | ON | 進捗画面を画面いっぱいに広げる |
| 👕 3D スキンレイヤー | ON | 帽子・上着・袖・ズボンを立体にする |
| 👀 自由視点 | ON | `F5` を長押しすると、カメラだけを回せる |
| 🎬 AFK シネマティック | ON | 30 秒操作しないと、映画のような視点で自分を映す |
| 🔊 サウンドブラウザ | ON | クリエイティブ画面で、ゲームの音を探して試聴する |
| ✅ クリックの確認を省略 | ON | 本・チャットのコマンドやリンクを、確認なしで実行する |
| ✨ エンチャントの効果 | OFF | エンチャントの数値の効果を説明に出す |
| 🧱 スポナー情報 | OFF | 近くのスポナーを光らせ、範囲と中身を表示する（管理者のみ） |

---

## ❱ 操作【Controls】

| 操作 | 動作 | 操作 | 動作 |
|---|---|---|---|
| `M` | ワールドマップ | 素手で右クリック長押し | ズーム |
| `F5` 長押し | 自由視点 | `F5` | 視点の切り替え |
| マップで右クリック | ピンを置く | マップで `Ctrl+左クリック` | その場所へ移動（管理者のみ） |
